# NeuroChunk Trainer

基于神经科学「语音chunking」与「预测性加工」原理的 L2 沉浸式听力训练平台。使用 Next.js 和 FastAPI 构建。

## 功能特性
- 实时 Chunk Tapping
- Predictive Shadowing (预测跟读)
- Rhythmic Immersion (节奏同步)
- Statistical Discovery (统计学习浸泡)

## 架构
- **Frontend**: Next.js 15, React, Tailwind CSS, shadcn/ui
- **Backend**: FastAPI, Python 3.11, LangGraph
- **AI / Audio API**: 小米 MiMo API (V2.5-ASR/TTS/Omni)
